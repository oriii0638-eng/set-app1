# אפליקציית סט ל-Apple Watch

## מה יש בשעון
- **אימון היום**: אותו אימון שמופיע באפליקציה בטלפון, עם המשקלים מהפעם הקודמת.
- **סימון סטים**: כפתור גדול "סט בוצע". נגיעה בסט פותחת עריכה: משקל עם הכתר הדיגיטלי, חזרות עם + ו־−.
- **טיימר מנוחה עם רטט**: מתחיל לבד אחרי כל סט. רטט קל ב־3, 2, 1, רטט חזק בסוף, ותזכורת אחרי 30 שניות. יש כפתורי ‎+30 ודלג.
- **דופק וקלוריות בזמן אמת**: האימון נרשם ב-Apple Health כאימון כוח.
- **שמירה ביומן האימונים**: בסיום, האימון נשלח לשרת ומופיע בטלפון ביומן האימונים, עם רצף ותגים. אם אין חיבור, השעון שומר אותו ושולח אחר כך.

- **סנכרון חי עם הטלפון**: מתחילים אימון בטלפון והשעון נפתח ומצטרף לבד (וגם להפך: אימון שהתחיל בשעון מופיע בטלפון). כל סט שמסמנים או משנים באחד מופיע בשני תוך 2–3 שניות. מי שמסיים את האימון שומר אותו, והצד השני נסגר בלי לשמור פעמיים. הדופק והקלוריות מהשעון נשמרים גם באימון שמסתיים בטלפון.
- **ספירת חזרות אוטומטית (ניסיוני)**: בזמן הסט השעון מודד את תנועת היד ומציג "נספרו X חזרות". כשמסמנים את הסט, המספר נרשם (אפשר לתקן בנגיעה על הסט). אפשר לכבות בתחתית מסך האימון. עובד הכי טוב בתרגילים שהיד זזה בהם למעלה ולמטה.

## איך השעון מתחבר לחשבון
**אוטומטית:** אם סט מותקנת בשעון, האפליקציה בטלפון מחברת אותו לבד (תוך כמה שניות מפתיחת סט בטלפון). אם זה לא קרה:
1. בשעון: לפתוח את סט וללחוץ "התחבר עם קוד". מופיע קוד בן 6 ספרות.
2. בטלפון: פרופיל ← כרטיס **⌚ Apple Watch** ← להקליד את הקוד ← חבר.
3. מאותו רגע הטלפון מסנכרן את אימון היום לשעון.

## הוספת השעון לפרויקט (על המאק, רק מהטרמינל)
```
cd ~/Documents/set-app1/ios-app && git pull && bash watch/install-watch.sh
```
הסקריפט סוגר את Xcode, מתקין כלי לעריכת הפרויקט (בפעם הראשונה), מוסיף Target בשם "SetWatch Watch App" עם HealthKit, Workout processing ואייקון, מטמיע אותו באפליקציית האייפון, ופותח את Xcode מחדש.
אחרי עדכון של קוד השעון מריצים את אותה פקודה שוב.

מכאן `bash upload-build.sh <מספר>` בונה ומעלה את האייפון ואת השעון יחד.

## לפני הגשה ל-App Store
- ב-App Store Connect, בגרסה החדשה: להעלות **צילומי מסך של השעון** (בחלק Apple Watch). בלי זה אי אפשר להגיש.
- בהערות לבודק: השעון מתחבר בקוד מהפרופיל באפליקציה בטלפון. אפשר להשתמש בחשבון הבדיקה הרגיל.
